# Security Policy

## Scope

This repository is an educational defensive-security project intended for authorized testing, local labs, public benchmark analysis, and secure engineering.

## Responsible use

Do not use this code to scan, access, exploit, exfiltrate from, or modify systems without explicit permission. Do not connect demo adapters to production accounts, unrestricted shell tools, private personal data, or real credentials.

## Reporting a vulnerability

If you find a software defect that could cause unsafe behavior, open a private report with a clear description, reproduction steps using only local fixtures, impact assessment, and a proposed mitigation. Never include real secrets or personal data in an issue.

## Data handling

Use only datasets whose licenses and terms permit the intended use. Keep credentials in environment variables and never commit secrets. Synthetic identifiers in fixtures are not real users.
## Private reporting

Please use a private GitHub Security Advisory or contact [@niketkrishnan](https://github.com/niketkrishnan). Do not include real credentials, production telemetry, or personal data in public issues.
